# Doggy-Daycare

Static front-page prototype for daycare workflows.

## Pages

- `/index.html` - landing page linking all flows
- `/admin.html` - customer management, appointment scheduling, and photo uploads
- `/owner-portal.html` - owner booking, pre-pay, and photo access
- `/shop.html` - merch plus dog/cat food and cat litter offerings

## Quick start

Open `index.html` from the project root in a browser.
